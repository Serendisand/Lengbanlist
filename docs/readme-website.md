# Lengbanlist 在多平台

插件在下面这些地方都能找到。认准作者 **Serendisand**，别处的「Lengbanlist」多半是二次打包的。

| 平台 | 链接 | 适合做什么 |
| --- | --- | --- |
| GitHub | https://github.com/Serendisand/Lengbanlist | 源码、Release 下载、提 Issue。**最新版本与问题反馈的首选** |
| Modrinth | https://modrinth.com/plugin/lengbanlist | 按版本筛选下载，跟进更新 |
| SpigotMC | [Lengbanlist - 冷禁列表](https://www.spigotmc.org/resources/lengbanlist-%E5%86%B7%E7%A6%81%E5%88%97%E8%A1%A8.123623/) | 英文服主常用的资源页 |
| 苦力怕论坛 | https://klpbbs.com/thread-154852-1-1.html | 中文社区讨论与反馈 |
| Discord | https://discord.gg/aeWjf7vD | 交流、提问、聊新功能 |

配套仓库：

| 仓库 | 内容 |
| --- | --- |
| [Lengbanlist-Models](https://github.com/Serendisand/Lengbanlist-Models) | 角色模型：插件里每一句提示语的措辞与语气 |
| [Lengbanlist-Extensions](https://github.com/Serendisand/Lengbanlist-Extensions) | 官方扩展源码，也是写 Lua 扩展时最好的参考 |

## 下载与更新

- 单 jar 通吃 1.17.1 ~ 26.3+，服务端是 Spigot / Paper / Folia 都能用；
- 换版本直接替换 jar 即可，配置与数据会保留；
- 开启自动更新后，插件会自己检查 Release 并下载新 jar，重启生效。
